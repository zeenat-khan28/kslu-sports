This folder is exclusively for the gallery and the home page slideshow.

HOW TO USE:
1. Simply copy and paste any images (jpg, png, webp, etc.) into this folder.
2. The website will automatically detect them.
3. The home page carousel and the Gallery page will update instantly.
4. If this folder is empty, the website will show a tasteful default banner.

Note: Do not put folders inside here, just the image files directly.
